# SIGIL LABS — Creative Engineering & Autonomous Systems

> "El chip es el sello. La corriente es la voluntad."

Unidad de ingeniería creativa y desarrollo inmersivo orientada a la construcción de ecosistemas digitales, arquitecturas agénticas con IA y experiencias visuales de alta precisión cinemática.

---

## ⚡ Core Tecnológico

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org) + React 19
- **Motion & Cinematic Physics**: GSAP 3.13 (`@gsap/react`), ScrollTrigger, SplitType
- **Smooth Scrolling**: Lenis Smooth Scroll
- **Seamless Page Transitions**: `next-view-transitions`
- **Iconografía & HUD**: React Icons (`react-icons`)
- **Estética Visual**: Cyber-brutalismo de lujo, Solomonic Circuit SVG, micro-interacciones de pulso cuántico
